### Quest Milestones UI (#163)

- Add QuestMilestonesPanel component to quest detail pages
- Milestone list displays with status indicator, color dot, and entity links
- Features:
  - Up/down reorder buttons for sorting milestones
  - Click status dot to cycle through statuses (pending → in_progress → completed → failed)
  - Inline add/edit form for creating and modifying milestones
  - Support for linked entities (character, location, etc)
  - Color indicator support for milestone categories
  - Delete milestone with confirmation
